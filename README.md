# Real-Time Character Calculator

A simple web app that counts the number of characters in a text input and limits it to 50 characters, all while maintaining an attractive and user-friendly interface.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📦 Installation

1. **Download or Clone** this repository:
   ```bash
   git clone https://github.com/yourusername/real-time-character-calculator.git
Run the Project:

Open the index.html file in your browser to use the character calculator.

👥 Features
Real-time character count.

Limits text input to 50 characters.

Clean and responsive user interface.

Provides a visual warning when the character limit is about to be reached.
